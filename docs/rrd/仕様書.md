## 1. 概要

### 1.1 目的

RazorReportServerは、Blazor Serverアプリケーションで実装されたWYSIWYG（What You See Is What You Get）方式のレポートデザイナーです。
プレビューをHTML DOM上で構築しつつJSON形式でレイアウトデータを保存します。
Microsoft純正Razorエンジンでパラメータを渡してHTMLに変換します。完成したレポートはPlaywrightによるPDF変換で出力できます。

### 1.2 主な機能

- **Blazorベースの WYSIWYG デザイナー**: HTMLコンポーネントによるドラッグ&ドロップで直感的にレポートをデザイン
- **Microsoft 純正 Razor エンジン**: Blazor組み込みのテンプレートエンジンによる柔軟なデータバインディング
- **プレビュー機能**: デザイン内容をリアルタイムで表示・確認（同一ページ内表示）
- **PDF出力**: Playwright によるPDF変換（高度なレイアウト制御に対応）
- **グリッドシステム**: A4ベースのグリッド分割による整ったレイアウトのためのスナップ機能
- **リッチテキスト編集**: フォント、スタイル、色などの詳細なテキスト編集

### 2.3 システム境界

- **入力**: ユーザーのマウス・キーボード操作（Blazor UI経由）、ファイル読み込み
- **出力**: JSONファイル（.rrd / .json）、PDFファイル
- **通信**: SignalR（Blazor Server ↔ WebView2（ブラウザ）、localhost内なので遅延なし）
- **中間生成物**: Razorテンプレート（メモリ上でのみ生成、直接保存はしない）
- **外部依存**: WebView2ランタイム、Blazor Server ランタイム、Playwright Edge

## 3. 機能仕様

### 3.1 UI構成

#### 3.1.1 レイアウト構造

UIはBlazorのサイドバー（Drawer）方式で構成されています。ツールバーは固定表示され、ツールおよびパラメータパレットとプロパティパネルは左右に固定配置されたサイドバーとして実装されています。

```
┌─────────────────────────────────────────────────────────────────────┐
│ ツールバー（固定表示：フォント、スタイル、配置、保存、プレビュー等）│
├──────┬──────────────────────────────────────────────┬──────────────┤
│      │                                              │              │
│ ツール│                                              │ プロパティ    │
│ および│        デザインエリア                        │ パネル        │
│ パラ │      （A4ベースのグリッド表示）               │              │
│ メー │                                              │ [ピンアイコン]│
│ タ   │                                              │              │
│ パレ │                                              │              │
│ ット │                                              │              │
│      │                                              │              │
│ [ピン│                                              │              │
│ アイ │                                              │              │
│ コン]│                                              │              │
│      │                                              │              │
└──────┴──────────────────────────────────────────────┴──────────────┘
```

**サイドバーの特徴**:
- ツールおよびパラメータパレット（左側）とプロパティパネル（右側）は、MudBlazorのMudDrawerコンポーネントを使用して実装
- 各サイドバーにはピンアイコンが表示され、ピン止め機能で表示/非表示を制御
- **ピン止めON**: サイドバーが常時表示される（Persistentモード）
- **ピン止めOFF**: サイドバーが折りたたまれる（Temporaryモード、必要に応じて展開可能）
- サイドバーの表示/非表示状態（ピン止め状態）はセッション中保持される
- シンプルな実装で、高度なDock機能は不要
- 詳細は[3.1.9 サイドバー](#319-サイドバー)を参照

#### 3.1.2 ビューモード

- **デザインビュー**（"Draft"モード）: レポートのレイアウト編集モード
  - HTML コンポーネント（CSSグリッド）で実装
  - グリッド表示（グリッド線ON）
  - コンポーネントの配置・編集
  - プロパティ編集
  - WYSIWYG方式のみ（HTMLは直接編集不可）

- **プレビュービュー**（"Preview"モード）: レンダリング結果の表示モード
  - HTML コンポーネント（CSSグリッド、グリッド線OFF）で表示
  - 実際のデータを適用したプレビュー

**用語の対応**: 「デザインビュー」= "Draft"モード、「プレビュービュー" = "Preview"モード。設定ファイルでは`DefaultDisplayMode`と`SupportedDisplayModes`で管理されます。

**WYSIWYG編集ポリシー**:
- HTMLは直接編集不可（WYSIWYGのみ）
- すべての編集は視覚的な操作で行う
- コンポーネントの配置、スタイル設定、プロパティ編集はすべてUI操作で実施

#### 3.1.3 ツールおよびパラメータパレット

- **位置**: 左側サイドバー
- **機能**: コンポーネント一覧とパラメータ管理を統合表示
- **実装**: MudBlazorのMudDrawerコンポーネントを使用

**ピン止め機能**:
- サイドバーヘッダーにピンアイコンを表示
- **ピン止めON**: サイドバーが常時表示される（Variant="Persistent"）
- **ピン止めOFF**: サイドバーが折りたたまれる（Variant="Temporary"、非表示）
- 折りたたみ時は左端にアイコンまたはタブとして表示され、クリックで一時的に展開可能
- パネルの表示/非表示状態（ピン止め状態）はセッション中保持される

**コンポーネント一覧**:
- テキスト
- 画像
- テーブル
- レイアウトコンポーネント

**パラメータ管理**:
- 検索ボックス（絞り込み用）
- パラメータ一覧（キー・値の編集）
- パラメータの追加、編集、削除
- ドラッグ&ドロップでコンポーネントに配置可能

**操作**:
- コンポーネント: クリックで選択（配置モード有効化）→デザインエリアで範囲をドラッグして配置
- パラメータ: ドラッグ&ドロップでコンポーネントに値を配置（自動的に`@dic["key"]`形式のRazorコードに変換）

パラメータの配置ルールの詳細は[コンポーネントとパラメータ定義 - パラメータの配置ルール](仕様書_コンポーネントとパラメータ.md#パラメータの配置ルール)を参照してください。

#### 3.1.4 ツールバー

ツールバーには基本操作、フォントスタイル、フォント設定、配置、配置揃えの各機能が含まれます。

**主要機能**:
- **ズーム機能**: デザインエリアの表示倍率を変更可能（50%〜200%）。ズームイン/アウトボタン、ズーム値選択、ページフィット機能を提供。
- **ページ設定**: 用紙サイズ（A4、A3、A5、Letter、Legal、B4、B5、カスタム）とページ向き（縦/横）を選択可能。デフォルトはA4縦向き。
- **グリッド表示**: グリッド線のON/OFF切り替え、表示分割数の変更（36, 30, 24, 18列）。

詳細は[ツールバー定義](仕様書_ツールバー.md)を参照してください。

#### 3.1.5 プロパティパネル

- **位置**: 右側サイドバー
- **機能**: 選択中の要素のプロパティを編集
- **実装**: MudBlazorのMudDrawerコンポーネントを使用

**ピン止め機能**:
- サイドバーヘッダーにピンアイコンを表示
- **ピン止めON**: サイドバーが常時表示される（Variant="Persistent"）
- **ピン止めOFF**: サイドバーが折りたたまれる（Variant="Temporary"、非表示）
- 折りたたみ時は右端にアイコンまたはタブとして表示され、クリックで一時的に展開可能
- パネルの表示/非表示状態（ピン止め状態）はセッション中保持される
- 要素が選択されていない場合でも、ピン止めされていればパネルは表示される

**表示条件**:
- 要素が選択されている場合、またはピン止めされている場合に表示
- ピン止めされていない場合、要素が選択されている時のみ表示

**単一選択時**:
- 選択された1つのコンポーネントのプロパティを表示・編集可能
- すべてのプロパティが個別に編集可能

**複数選択時**:
- 複数のコンポーネントが選択されている場合、プロパティパネルで一括設定が可能
- **一括設定可能なプロパティ**: 位置（column, row）、サイズ（columnSpan, rowSpan）、フォントファミリー、フォントサイズ、フォントカラー、背景色、配置、参照プロパティなど、複数のコンポーネントタイプで共通するプロパティ
- **一括設定の動作**: プロパティパネルで値を変更すると、選択中のすべてのコンポーネントに同じ値が適用される
- **個別プロパティ**: コンポーネントタイプ固有のプロパティ（例: テキストコンポーネントのテキスト内容、画像コンポーネントの画像ファイルパスなど）は、複数選択時は表示されない、または個別に設定できない

#### 3.1.6 デザインエリア

- **位置**: 中央（左右のサイドバーに挟まれた領域）
- **実装**: Blazor Razorコンポーネント + CSSグリッド
- **機能**: レポートのデザイン編集領域
- **レイアウト**: サイドバーが非表示（ピン止めOFF）になった場合、デザインエリアが自動的に拡張される
- **特徴**:
  - CSSグリッドで直接レイアウト（列数・行数は現在のページサイズと向きに応じて`appsettings.papers.json`から読み込まれる。A4縦=36列×51行、A4横=51列×36行、A3横=72列×51行、A3縦=51列×72行など）
  - グリッド線はCSS background-imageで自動描画
  - グリッド線のON/OFF切り替え可能（デフォルトON）
  - 要素配置時に必ずグリッドセルにスナップ（常時有効、オフ不可）
  - スクロール可能
  - グリッド範囲選択対応（Excelライクな範囲選択）
  - 範囲選択時のコンポーネント貼り付け対応
  - 範囲選択時のテーブル作成対応
  - 要素の複数選択対応（SHIFT+クリック）
  - 表示用分割数の切り替え（36, 30, 24, 18列）
  - **列ヘッダー・行ヘッダー**: Excelライクな列ヘッダー（A, B, C, ..., AJ）と行ヘッダー（1, 2, 3, ..., 51）を表示
    - 固定ヘッダーとしてスクロール時も常に表示
    - A1形式とR1C1形式の両方でセルを識別可能
    - マウスホバー時と選択時にセル番号を表示

#### 3.1.7 操作インタラクション

**キーボード操作**:
- Ctrl+C: コピー、Ctrl+V: ペースト、Delete: 削除、Escape: 選択解除
- Ctrl+Z/Y: 元に戻す/やり直す（将来拡張）

**マウス操作**:
- 左クリック: 要素選択、Shift+クリック: 複数選択
- ダブルクリック: コンポーネントの編集モード起動（テキスト=インライン編集、画像=ファイル選択、テーブル=セル編集）
- ドラッグ: グリッド範囲選択、コンポーネント移動
- 右クリック: コンテキストメニュー表示（コピー、切り取り、削除、複製、プロパティ、ペースト、すべて選択）

#### 3.1.8 デザインエリア拡張領域

**ページ範囲外への配置**: 現在のページサイズの範囲（例：A4縦=36列×51行、A3横=72列×51行、A3縦=51列×72行）外にもコンポーネント配置可能。デザイン時は無制限拡張、プレビュー/PDF出力時はページ範囲外要素は非表示（警告アイコン表示）。JSON保存時はすべての要素位置を記録。

**複数選択操作**: 列/行ヘッダークリックで全体選択、ドラッグで範囲選択、Shift+クリックで範囲追加、Ctrl+Aで全選択、Escで選択解除。選択範囲は一括移動・削除・スタイル変更・コピー/ペーストが可能。選択セルはハイライト表示、選択範囲の数値情報（「3列×5行」など）を表示。

#### 3.1.9 サイドバー

**パネル構成**: ツールおよびパラメータパレット（左側）、プロパティパネル（右側）。各サイドバーは左右に固定配置され、ピン止め機能で表示/非表示を制御可能。

**サイドバーの動作**:
- 左側と右側に固定配置（MudBlazorのMudDrawerを使用）
- ピン止め機能による表示/非表示制御
- **ピン止めON**: Persistentモード（常時表示）
- **ピン止めOFF**: Temporaryモード（折りたたみ、必要に応じて展開）
- パネル状態（ピン止め状態）のセッション保持

**実装方式**: MudBlazorのMudDrawerコンポーネントを使用して実装。VariantプロパティでPersistent（常時表示）とTemporary（折りたたみ）を切り替える。

### 3.2 デザイナー機能

#### 3.2.1 グリッドシステム

**基本方針**: ページサイズに応じたグリッド分割システム。各ページサイズに対応するグリッド列数は`appsettings.papers.json`で定義されます。内部データは常に基準列数で保存し、表示時のみ表示用分割数から選択可能。ページサイズはツールバーから変更可能（A4、A3、A5、Letter、Legal、B4、B5、カスタム）。

**ページサイズ別のグリッド分割**:
- **A4縦（210mm × 297mm）**: 36列×51行（基本サイズ）
- **A4横（297mm × 210mm）**: 51列×36行
- **A3縦（297mm × 420mm）**: 51列×72行
- **A3横（420mm × 297mm）**: 72列×51行（A4縦2枚を横に並べた大きさ）
- **A5縦（148mm × 210mm）**: 25列×36行
- **A5横（210mm × 148mm）**: 36列×25行
- **その他のページサイズ**: `appsettings.papers.json`で定義された列数・行数を使用

**ページサイズ別グリッド設定の基本原則**:
- ページサイズと向き（縦/横）により、`appsettings.papers.json`で定義されたグリッド列数・行数を使用
- 各用紙サイズでセルサイズは独自に定義（A4縦セルサイズ: 約5.833mm × 5.824mm）
- 向き変更時は、列数と行数を入れ替えて対応（例：A4縦 36列×51行 ↔ A4横 51列×36行）
- A3横がA4縦2枚を横に並べた大きさになるよう設計（A3横 420mm × 297mm = 72列×51行）

**注意**: グリッドデザインは分割数（列数×行数）のみを使用し、px値は参考値として記載しています。実際の配置はグリッドセル単位（column, row, columnSpan, rowSpan）で管理されます。各ページサイズのグリッド設定は`appsettings.papers.json`から読み込まれます。

**ページサイズ変更時の動作**:
- ページサイズ変更時は、`appsettings.papers.json`から対応するページサイズの設定を読み込む
- グリッド列数・行数は`appsettings.papers.json`で定義された値を使用（A4=36列、A3=72列など）
- 既存要素の位置は可能な限り保持（スケーリングではなく、グリッドシステムの再計算）
- ページ向き（縦/横）の変更時も同様にグリッドシステムを再計算
- カスタムサイズはmm、px、inchの単位に対応（`appsettings.papers.json`で定義、またはA4基準で比例計算）

**配置方式**:
- すべてのコンポーネントはグリッドセル単位（column, row, columnSpan, rowSpan）で配置
- 要素の配置・移動・リサイズ時は常にグリッドセルにスナップ（常時有効、オフ不可）
- JSONにはセル位置とサイズを保存

**グリッド表示**:
- グリッド線はデフォルトON（ツールバーで切り替え可能）
- 表示分割数の切り替えは視覚的表現のみ（内部データは36列基準のまま）

**グリッド範囲選択**:
- Excelライクな範囲選択（ドラッグで複数セル選択）
- 選択範囲にコンポーネントを配置可能（選択範囲のサイズに合わせて自動配置）
- 選択範囲からテーブル作成可能（ツールバーの「テーブル作成」ボタン）

**グリッドヘッダー**:
- **列ヘッダー**: デザインエリアの上側に列ヘッダーを表示（A, B, C, ..., Z, AA, AB, ...）
  - A4縦の場合は36列まで対応（A～AJ）、A4横の場合は51列まで対応（A～AY）
  - A3横の場合は72列まで対応（A～BZ）、A3縦の場合は51列まで対応（A～AY）
  - 固定ヘッダーとしてスクロール時に固定表示（position: sticky）
- **行ヘッダー**: デザインエリアの左側に行ヘッダーを表示（1, 2, 3, ...）
  - A4縦の場合は51行まで対応、A4横の場合は36行まで対応
  - A3縦の場合は72行まで対応、A3横の場合は51行まで対応
  - 固定ヘッダーとしてスクロール時に固定表示（position: sticky）
- **セル番号形式**: A1形式とR1C1形式の両方をサポート
  - **A1形式（デフォルト）**: 列=A-Z、行=1-51（例：A1, B2, AA10）
  - **R1C1形式**: 列=R1C1, R1C2, ...、行=R1C1, R2C1, ...（例：R1C1, R2C3）
  - ツールバーまたは設定で切り替え可能
- **セル識別の表示**:
  - **マウスホバー時**: セル上にマウスを置いた際に、セル番号をツールチップまたはステータスバーに表示
  - **選択時**: セルまたはコンポーネント選択時に、プロパティパネルとステータスバーにセル番号を表示
  - **範囲選択時**: 選択範囲の開始セルと終了セルを表示（例：A1:C5 または R1C1:R5C3）

**実装**: Blazor Razorコンポーネント + CSSグリッド。JSONの `(column, row, columnSpan, rowSpan)` がCSSグリッド配置に直接変換される。セル番号変換は`Aloe.Apps.RazorReportLib.GridCellReference`クラスで実装。ページサイズとグリッド設定は`appsettings.papers.json`から読み込まれる。

**コンテナとsubgrid**:
- コンテナコンポーネントはCSS subgridを使用して親グリッドを継承
- コンテナがスパンする範囲（columnSpan × rowSpan）内で、親グリッドのトラックサイズを継承
- コンテナ内の子要素は、継承されたグリッドに対して相対座標で配置される
- 実装: コンテナに `display: grid` と `grid-template-columns: subgrid` / `grid-template-rows: subgrid` を適用
- ブラウザサポート: Chrome 117+, Firefox 71+, Safari 16+（PlaywrightのEdgeでもサポート）

#### 3.2.4 選択機能

**コンポーネント選択**: クリックで単一選択、Shift+クリックで複数選択、ドラッグで範囲選択、Ctrl+Aで全選択。選択されたコンポーネントには選択ハンドルとリサイズハンドルを表示し、プロパティパネルにプロパティを表示。グリッド範囲選択の詳細は[3.2.1 グリッドシステム](#321-グリッドシステム)を参照。

**リサイズハンドル**:
- **表示条件**: コンポーネントが選択されている時のみ表示
- **位置**: コンポーネントの四隅と各辺の中点（計8箇所）
  - 四隅: 左上、右上、左下、右下
  - 各辺の中点: 上辺中央、下辺中央、左辺中央、右辺中央
- **カーソル**: 各ハンドルで適切なリサイズカーソルを表示
  - 四隅: 斜め方向のリサイズカーソル（↖、↗、↙、↘）
  - 上下辺: 垂直方向のリサイズカーソル（↕）
  - 左右辺: 水平方向のリサイズカーソル（↔）
- **操作**: リサイズハンドルをドラッグすることで、コンポーネントのサイズを変更
- **スナップ**: リサイズ時もグリッドセルにスナップ（常時有効、オフ不可）
- **最小サイズ**: すべてのコンポーネントは最小1×1グリッドセルサイズを維持

**選択ハンドル**: 選択されたコンポーネントの周囲に表示される視覚的なインジケーター。コンポーネントの境界を明確に示します。

#### 3.2.7 ダブルクリック編集機能

##### 全コンポーネント対応

すべてのコンポーネントでダブルクリックによる編集をサポート：

- **テキストコンポーネント**: ダブルクリックでインライン編集モード（テキスト内容の直接編集）
- **画像コンポーネント**: ダブルクリックで画像ファイル選択
- **テーブルコンポーネント**: ダブルクリックでセル編集モード（セル内のテキスト編集）
- **コンテナ/セクション**: ダブルクリックでプロパティパネルを表示

##### 編集モード

- **インライン編集**: テキストコンポーネントやテーブルセルで、その場で編集可能な状態にする
- **モーダル編集**: 画像やコードブロックなど、複雑な編集が必要な場合はBlazor ダイアログで実装
- **編集終了**: Enterキー、Escキー、またはフォーカスアウトで編集終了

#### 3.2.8 コンポーネント配置機能

コンポーネントの配置には、以下の2つの方法があります：

**方法1: クリック選択→範囲ドラッグ（2段階操作）**: 
- **第1段階**: ツールおよびパラメータパレットでコンポーネントをクリックして選択（配置モード有効化）
  - 選択されたコンポーネントは視覚的にハイライト表示
  - マウスカーソルが配置可能な状態を示すアイコンに変更
  - デザイナ側でドラッグ可能な状態になる
- **第2段階**: デザインエリア内で範囲をドラッグして配置
  - 配置モード中は通常のグリッド範囲選択とは分離したモードとして動作
  - ドラッグ中は範囲をハイライト表示（視覚的フィードバック）
  - ドロップ時に選択されたコンポーネントを、ドラッグした範囲のサイズ（columnSpan, rowSpan）で配置
  - 配置後、配置モードを自動解除
- **配置モードのキャンセル**: Escapeキーで配置モードを解除、またはデザイナ外をクリックで解除
- **配置モード中の操作**: 別のコンポーネントを選択した場合は新しいコンポーネントに切り替え、範囲ドラッグが1セル未満の場合は最小サイズ（1×1）で配置

**方法2: ドラッグ&ドロップ（直接配置）**:
- **ドラッグ開始**: ツールおよびパラメータパレットのコンポーネントアイテムをドラッグ開始
- **ドラッグ中**: カーソルが配置可能アイコンに変更、デザインエリア上でドロップ可能位置をハイライト表示
- **ドロップ**: ドロップ位置のグリッドセルに、設定ファイル（`appsettings.components.json`）で定義されたデフォルトサイズで自動配置
- **配置後**: 配置されたコンポーネントを自動選択し、通常の編集モードに移行

**データの配置**: ツールおよびパラメータパレットからコンポーネントへドラッグ&ドロップで、自動的に`@dic["key"]`形式のRazorコードに変換。テキストコンポーネントは既存テキストに追加または置換、テーブルセルはセル内容を置換。

**コンポーネントの移動**: デザインエリア内で既に配置されたコンポーネントを選択し、コンポーネント本体（リサイズハンドル以外の領域）をドラッグして移動。ドラッグ中は半透明プレビューを表示し、グリッドスナップ位置を表示。ドロップ時にグリッド座標に変換してJSONを更新。他のコンポーネントとの重なりは許可（z-indexで制御）。

**コンポーネントのリサイズ**: 配置済みのコンポーネントを選択すると、8方向のリサイズハンドルが表示されます。リサイズハンドルをドラッグすることで、コンポーネントのサイズを変更できます。リサイズ中はサイズ変更のプレビューを表示し、グリッドセル単位でスナップします。詳細は[3.2.4 選択機能](#324-選択機能)を参照してください。

**視覚的フィードバック**: 配置モード中はカーソル変更、ドラッグ中は範囲のハイライト表示、配置後のコンポーネント移動時は半透明プレビュー表示、ドロップ可能領域をハイライト、スナップ位置を表示。

#### 3.2.9 WYSIWYGエディタ機能

**リッチテキスト編集**: テキストコンポーネント選択時にツールバーでフォントスタイル（Bold、Italic、Underline、Strikethrough）、フォント設定（ファミリー、サイズ、カラー）、配置（左、中央、右、両端）を設定可能。

**インライン編集**: テキストコンポーネントをダブルクリックでインライン編集モード起動。編集中もリアルタイムでスタイル反映。Enter/Escキーまたはフォーカスアウトで終了。

**スタイル適用範囲**: テキストの一部を選択してスタイル適用、またはコンポーネント全体にスタイル適用。

#### 3.2.10 フォント管理

**Googleフォント**: HTML出力時に使用されているGoogleフォントを自動検出し、`<link>`タグで読み込む。必要なフォントのみを読み込んでパフォーマンス最適化。

**フォント選択UI**: システムフォントとGoogleフォントを統合表示。プリセットフォント（Noto Sans JP、Roboto等）を提供。カスタムフォントURLの入力も可能。フォント選択時にプレビュー表示（日本語・英語の両方で確認）。

### 3.3 レイアウトデータ管理

#### 3.3.1 保存形式

- **ファイル形式**: JSON形式で保存
- **ファイル拡張子**: `.rrd`（RazorReportDesigner）または `.json`
- **エンコーディング**: UTF-8
- **管理方式**: Razorファイルとして直接管理せず、JSONで管理

#### 3.3.2 JSON構造

レイアウトデータは以下のJSON構造で保存：

```json
{
  "version": "1.0",
  "grid": { "columns": 36, "rows": 51, "columnWidth": 22.05, "rowHeight": 22.05 },
  "pageSize": { "name": "A4", "width": 793.7, "height": 1122.52, "unit": "px", "dpi": 96 },
  "elements": [
    {
      "type": "TextElement",
      "id": "text-1",
      "position": { "column": 0, "row": 0, "columnSpan": 12, "rowSpan": 2 },
      "properties": { "text": "サンプルテキスト", "fontFamily": "Noto Sans JP", ... },
      "customProperties": {}
    }
  ],
  "metadata": { "createdAt": "...", "updatedAt": "...", "gridColumns": 36, "pageSizeName": "A4" }
}
```

**主要項目**:
- `grid`（グリッド設定、`columns`と`rows`が実際に使用され、`columnWidth`と`rowHeight`は参考値。ページサイズと向きに応じて値が変わる：A4縦=36列×51行、A4横=51列×36行、A3縦=51列×72行、A3横=72列×51行など）
- `pageSize`（ページサイズ情報、`name`でページサイズ名を指定、`width`/`height`は参考値）
- `elements`（要素配列）
- `metadata`（メタデータ、`gridColumns`と`pageSizeName`で現在のページサイズとグリッド列数を記録）

各要素は`type`、`id`、`position`（column, row, columnSpan, rowSpan）、`properties`（要素固有のプロパティ）、`customProperties`を持つ。位置情報はグリッドセル単位（分割数）で管理されます。ページサイズ変更時は、`grid.columns`と`grid.rows`が`appsettings.papers.json`で定義された値に更新されます。

#### 3.3.3 JSONからHTML/Razorへの変換

**変換タイミング**: プレビュー表示時、PDF出力時、エクスポート時。JSONデータを読み込み、Blazor RazorコンポーネントでHTMLに変換。

**変換処理**: JSONの各要素をCSSグリッドレイアウトで配置（`column` → `grid-column`, `row` → `grid-row`）。ルートコンテナのグリッド列数・行数は、現在のページサイズと向きに応じて`appsettings.papers.json`から読み込まれる（A4縦=36列×51行、A4横=51列×36行、A3縦=51列×72行、A3横=72列×51行など）。要素固有のプロパティ（フォント、色等）をスタイルとして反映。デザイン時と実行時は同じBlazorコンポーネントを使用（WYSIWYG原則）。

**パラメータ適用**: デザイン時はサンプル値を適用してリアルタイム表示、プレビュー時はグリッド線を非表示にして実際の出力イメージを表示、PDF出力時はパラメータ値を適用してHTML生成→PlaywrightでPDF変換。
