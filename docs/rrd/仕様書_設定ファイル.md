# 設定ファイル定義

このドキュメントでは、RazorReportで使用する各種設定ファイル（appsettings.json系）の構造と用途を定義します。

## 設定ファイル構成

設定ファイルは以下のように分割して管理します：

**ファイル構成**:
- `appsettings.json`: 基本設定（Logging、Grid、Layoutなど）
- `appsettings.papers.json`: ページサイズ定義（A4、A3、A5、Letter、Legal、B4、B5、カスタム）とグリッド分割設定
- `appsettings.parameters.json`: パラメータキー一覧とサンプル値
- `appsettings.components.json`: コンポーネントのデフォルトサイズ設定
- `appsettings.pdf.json`: PDF変換のデフォルト設定（用紙サイズ、マージン、印刷品質など）

**場所**: プロジェクトルートディレクトリ（Visual Studioのビルドプロセスで出力ディレクトリにコピー）

## appsettings.jsonの構造

```json
{
  "Logging": { ... },
  "RazorReportDesigner": {
    "Grid": {
      "DefaultColumns": 36,
      "DisplayColumns": [36, 30, 24, 18]
    },
    "Layout": {
      "DefaultDisplayMode": "Draft",
      "SupportedDisplayModes": ["Draft", "Preview"]
    }
  }
}
```

**Grid**:
- `DefaultColumns`（内部保存時の基本列数、A4の場合は36。ページサイズ変更時は`appsettings.papers.json`から対応する列数を読み込む）
- `DisplayColumns`（表示時に選択可能な列数。視覚的表現のみで、内部データは基準列数で保存）

**Layout**:
- `DefaultDisplayMode`（初期表示モード）
- `SupportedDisplayModes`（サポートされる表示モード）

**注意**: ページサイズ固有の設定（用紙サイズ、グリッド列数・行数、DPIなど）は`appsettings.papers.json`に移行されました。`appsettings.json`のGrid設定は基本設定のみを保持します。

- `name`: ページサイズの識別名（内部で使用、例：`A4-Portrait`、`A4-Landscape`）
- `displayName`: UI表示名（ユーザーに表示される、例：`A4 (縦)`、`A4 (横)`）
- `width`: ページ幅（単位は`unit`で指定）
- `height`: ページ高さ（単位は`unit`で指定）
- `unit`: サイズの単位（`mm`、`px`、`inch`）
- `orientation`: ページ向き（`portrait`=縦、`landscape`=横）
- `gridColumns`: グリッド列数（このページサイズと向きで使用する列数）
- `gridRows`: グリッド行数（このページサイズと向きで使用する行数）
- `dpi`: DPI設定（通常は96）

**ページサイズ別グリッド分割の基本原則**:
- 各用紙サイズ（A4、A3、A5等）で縦・横両方の設定を定義
- 向き変更時は列数と行数が入れ替わる（例：A4縦 36列×51行 ↔ A4横 51列×36行）
- A4セルサイズ（約5.833mm × 5.824mm）を基準に他のサイズを計算
- グリッド列数・行数は、ページサイズと向きごとに明示的に定義

**カスタムサイズ**: カスタムサイズの場合も、同様の構造で`appsettings.papers.json`に追加可能。`orientation`フィールドを含め、対応するグリッド列数・行数を定義。
