モバイル専用カレンダーページ 詳細仕様
================================

元の方針 `doc/mobile.txt` に基づき、実装着手可能な詳細仕様を本ファイルにまとめる。

--------------------------------

1. デバイス判定とルーティング
--------------------------------

1-1. デバイス判定
------------------

- `AuthController` のログイン処理時に `User-Agent` からモバイル判定を行う（既に UserAgent は取得済み）
- 判定ロジックの例: `iPhone|Android|Mobile` などの正規表現マッチ
- 判定結果を認証クッキーの Claims またはセッションに `IsMobile` として格納する
- ログインスキップ（`Home.razor`）時も同様に判定し、認証済みユーザーの遷移先を分岐する

1-2. ルーティング
------------------

- モバイル専用ルートを新設する: `/m/calendar`
- ログイン画面は共通 (`/login`) だが、ログイン成功後の遷移先を以下のように分岐する
  - PC: `/calendar`
  - モバイル: `/m/calendar`
- モバイル専用レイアウト `MobileCalendarLayout.razor` を新設し、`/m/calendar` で使用する
- 将来拡張用に `/m/list`, `/m/settings` などのモバイル専用ルートを追加できる前提で設計する


2. レイアウト構成
------------------

2-1. 全体レイアウト（MobileCalendarLayout）
-------------------------------------------

- 基準端末: iPhone SE (375 x 667) を想定する
- Tailwind + daisyUI を踏襲しつつ、モバイル前提の1カラム構成とする

画面レイアウトイメージ:

  +----------------------------------------------+
  | [≡]  [👤👤👤+2]              [🟢自アバター] |  ← Row1: ヘッダー上段
  | [月][日] [<]   2026年3月4日   [>] [今] [🔍]  |  ← Row2: ヘッダー下段（日付は中央寄せ）
  +----------------------------------------------+
  |                                              |
  |           カレンダー本体                      |  ← メインコンテンツ
  |           (月間 or 日間)                      |
  |                                              |
  +----------------------------------------------+
  |           選択日詳細エリア                     |  ← 日付選択時に表示
  +----------------------------------------------+
  |                                       [🎤]  |  ← マイク FAB（右下固定）
  +----------------------------------------------+

- ヘッダーは `sticky top-0` で画面上部に固定する
- カレンダー本体・詳細エリアは通常フロー（高さ制限なし）とし、ページ全体を縦スクロールできるようにする
- マイク FAB は `fixed bottom-4 right-4` 付近に配置し、常に画面右下に表示される

2-2. ヘッダー上段（Row1）
--------------------------

構成要素:

- ハンバーガー: `MobileHamburgerButton`
  - クラス例: `btn btn-sm btn-ghost`
  - タップでモバイル専用ドロワーメニュー（後述）を表示する
- アバターグループ: `MobileAvatarGroup`
  - daisyUI の `avatar-group` + counter を利用
  - 最大3人までアバターを表示し、残りは `+N` のカウンターで表現する
- 自アバター: `MobileSelfAvatar`
  - ステータスインジケーター付き（online / away / busy など）
  - タップで自アバター用メニュー（プロフィール・設定・ログアウトなど）を表示する

2-3. ヘッダー下段（Row2）
--------------------------

構成要素と動作:

- 「月」 / 「日」ボタン
  - ビュー切替ボタン（例: `btn btn-xs`）
  - 選択中のビューは `btn-primary` などで強調表示する
- 「<」「>」
  - 前後ナビゲーションボタン
  - 月ビュー時: 前月 / 翌月に移動
  - 日ビュー時: 前日 / 翌日に移動
- 日付表示
  - フォーマット: `x年y月z日(曜)`
  - 月ビューで日未選択の場合は `x年y月` 表示でもよい
  - `flex-1 text-center` を付与し、「<」「>」ボタンの間で中央寄せにする
- 「今」
  - 今日ボタン
  - 月ビュー時: 当月へジャンプ
  - 日ビュー時: 今日の日へジャンプ
- フィルターボタン（アイコン＋「フィルター」テキストなど）
  - クラス例: `btn btn-xs btn-ghost`
  - タップでモバイル用フィルターシート（後述）を開く
  - フィルターが有効な場合はバッジ（`badge badge-xs badge-warning`）で状態を示す


3. 月間カレンダー（簡易ビュー）
-------------------------------

3-1. DOM 構成
--------------

- コンポーネント名案: `MobileMonthCalendar.razor`
- Canvas は使用せず、CSS Grid (`grid-cols-7`) による DOM ベースでカレンダーを構築する
- 1週間を1行、7日ぶんのセルを `grid` で配置する
- 各セルには枠線を付ける（例: `border border-base-300`）

3-2. セルの構成
----------------

セルイメージ（重ね表示）:

  +--------+
  |  4     |  ← 日付番号（セル左上に小さく独立配置）
  |  ❸     |  ← 記号（薄く大きく表示、背景レイヤー）
  | [3/5]  |  ← 件数（記号の上に重ねて表示、前景レイヤー）
  +--------+
  ※ 記号と件数は同じ位置に重なって見える（縦積みではない）

- 日付番号
  - `text-xs` 程度の小さな文字サイズ
  - セル左上に独立配置（記号・件数エリアとは別ブロック）
  - 本日の日付は `badge badge-primary badge-xs` などで強調表示する
- 記号と件数の重ね表示（必須の実装方式）
  - セル下半分を `relative` コンテナとする
  - 記号（●▼×-）を `text-2xl opacity-30 select-none` でコンテナ中央に配置する（背景レイヤー）
  - `n/m` を `absolute inset-0 flex items-center justify-center text-[10px] font-bold` でその上に重ねる（前景レイヤー）
  - 縦並び（記号の下に件数を別行で表示する方式）は採用しない
- 当月外の日付はグレーアウト（例: `opacity-30`）
- 祝日は日付番号を `text-red-500` などで表示する
- 選択中セルは `bg-primary/10 ring-2 ring-primary` などで囲んで強調する
- セル高さは約 46px 前後を目安とし、最大6週表示でも iPhone SE 画面内に収まるよう全体の高さを調整する

3-3. 記号仕様（モバイル専用4種）
--------------------------------

本体側の実装（◎○△×–）を踏まえつつ、モバイルでは以下の4種類を使用する。

  - ● : 空きがある
  - ▼ : 少しだけ空き
  - × : 空きなし（満杯）
  - - : データなし（枠自体がないなど）

空き率に対する条件と Tailwind の色指定例:

  - ● : `vacancyRatio >= 0.3`
    - 色: `text-emerald-500`
  - ▼ : `0 < vacancyRatio < 0.3`
    - 色: `text-yellow-500`
  - × : `vacancyRatio <= 0`
    - 色: `text-red-500`
  - - : データなし（capacity=0 かつ available=0 など）
    - 色: `text-gray-400`

補足:

- デスクトップ版の「◎」「○」はモバイルでは「●」に統合する
- デスクトップ版の「△」はモバイルでは「▼」で表現する
- 空き率の計算ロジック自体はデスクトップ版（`slot-display-utils.js`）と同等とし、サーバーサイド（C#）で実装して値だけをモバイルコンポーネントに渡す

3-4. インタラクション
----------------------

- セルタップ:
  - 選択状態にする（選択ハイライトを付与）
  - ヘッダーの日付表示を選択した日付に更新する
  - カレンダー下部に選択日の詳細（後述）を表示する
- 長押し（ロングプレス）:
  - ボトムシートメニューを表示する（予約作成 / 仮予約作成）
  - メニューは `MobileLongPressMenu.razor` として実装する
- スワイプ左右（任意 / 将来対応でも可）:
  - 左スワイプで翌月、右スワイプで前月へ切り替える


4. 日間カレンダー（1日簡易ビュー）
-----------------------------------

4-1. DOM 構成
--------------

- コンポーネント名案: `MobileDayCalendar.razor`
- daisyUI の List コンポーネントのような縦リスト表示を採用する
- 時間帯ごとに1行ずつ表示し、ガタつかないよう各列の幅を固定する

4-2. リスト行の構成
--------------------

行イメージ:

  | 09:00 | ● | 3/5 |
  | 10:00 | ▼ | 4/5 |
  | 11:00 | × | 5/5 |
  | 13:00 | - | 0/0 |

- 左列: 時間帯
  - 例: `text-sm font-mono w-14` などの固定幅
  - 24時間表記（例: 09:00, 10:00, …）
- 中央列: 記号（●▼×-）
  - 例: `text-base w-6 text-center` で中央寄せ
  - 月間と同様の色指定を使用する
- 右列: `n/m` の件数
  - 例: `text-sm text-right w-12`
- 行タップ:
  - 選択状態にする（予約一覧のインライン展開は将来対応）
- 行長押し:
  - ボトムシートメニューを表示する（予約作成 / 仮予約作成）
- フィルターの結果で対象外となる時間帯:
  - 行全体に `opacity-30` を適用し、タップ不可とする（クリックイベントを無効化）


5. 選択日詳細エリア
--------------------

5-1. 表示タイミング
--------------------

- 月間ビューで日付をタップしたときに、カレンダー本体の下に表示する
- 初期状態（何も選択していない場合）は非表示または「日付を選択してください」程度の簡易メッセージとする

5-2. 構成
----------

- コンポーネント名案: `MobileDayDetail.razor`
- 表示内容:
  - 日付（例: `2026年3月4日(水)`）
  - 祝日名（あれば表示）
  - 当日の全体記号（●▼×- のいずれか）
  - 当日の全体件数（例: `10/20件`）
  - 時間帯サマリリスト（`MobileDayCalendar` と同様の行形式をコンパクトにしたもの）
- レイアウト:
  - ヘッダーは `sticky top-0` で固定し、カレンダー本体・詳細エリアは通常フロー（高さ制限なし）とする
  - ページ全体を縦スクロールできるようにし、`max-h-[33vh]` や `overflow-y-auto` の高さ制約は設けない
  - タップ操作で日間ビュー（`MobileDayCalendar`）に切り替える導線を用意してもよい（ボタンまたは行タップなど）


6. フィルター
--------------

6-1. UI 方針
-------------

- モバイル専用のフィルター UI を `MobileFilterSheet.razor`（仮）として作成する
- daisyUI の `modal modal-bottom` を用いて、ボトムシートまたはフルスクリーンモーダルとして表示する
- フィルター項目自体はデスクトップ版 `SearchFilterPanel` と同等の機能を持たせる
- **枠の二重化に注意**: `modal modal-bottom` を使うと daisyUI が `modal-box` を生成し、これがフィルターシートの外枠になる。
  `modal-box` の内部にさらに `card` や枠線付き `div` でフィルター項目を囲むと枠が二重になるため、
  `modal-box` の直下に項目リストと「適用/リセット」ボタンを直接配置し、内側に追加のカード・枠線を設けないこと。

  例:
  ```html
  <div class="modal modal-bottom">
    <div class="modal-box">
      <!-- ここに直接フィルター項目を配置 -->
      <div class="...">曜日トグル</div>
      <div class="...">時間帯チップ</div>
      <!-- 省略 -->
      <div class="flex gap-2 mt-4">
        <button class="btn btn-primary flex-1">適用</button>
        <button class="btn btn-ghost flex-1">リセット</button>
      </div>
    </div>
  </div>
  ```

6-2. フィルター項目
--------------------

想定項目と UI 例:

- 曜日
  - 横並びトグルボタン（7個: 日〜土）
  - 例: `btn btn-xs` を使用し1行に収まるようにする
- 時間帯
  - バッジ（`badge`）風のトグルチップ
  - 2行程度に収まるよう折り返して配置
- 空き枠数（必要人数）
  - 1〜4人は `btn-group` で選択
  - 5人以上は数値入力ボックスで指定
- フロア
  - チェックボックスのリスト
  - `collapse` で折りたたみ可能にする
- リソース
  - OR1 / OR2 といったグループ単位 + 個別チェックボックス
  - こちらも `collapse` で折りたたみ可能にする
- プラン
  - プラン種別のラジオボタン + オプションのチェックボックス

6-3. 操作
----------

- 下部に「適用」「リセット」ボタンを配置する
- フィルター適用中はヘッダーのフィルターアイコンに `badge badge-xs badge-warning` を表示し、状態を分かりやすくする
- フィルター条件は既存の `CalendarState` / `SearchFilterPanel` 相当の構造にマッピングし、デスクトップと同等の絞り込みができるようにする


7. FAB（フローティングアクションボタン）
-----------------------------------------

7-1. マイク FAB
----------------

- 既存の `VoiceCommandButton` のロジックを流用しつつ、モバイルでも常時表示する
- 配置:
  - `fixed bottom-4 right-4`（画面右下）
- 見た目:
  - クラス例: `btn btn-circle btn-primary shadow-lg`
  - 録音中は `btn-error` に変更し、パルスアニメーションなどで録音状態をわかりやすくする


8. ロングプレスメニュー
------------------------

- コンポーネント名案: `MobileLongPressMenu.razor`
- 表示形式:
  - daisyUI の `modal modal-bottom` によるボトムシートとして表示する
- メニュー項目:
  - 予約作成: `MobileAppointmentModal` をステータス=予約で開く
  - 仮予約作成: `MobileAppointmentModal` をステータス=待機中で開く
- 長押し判定:
  - 500ms 以上のポインターダウンで発火する
- 閉じる:
  - メニュー外タップで閉じる


9. ハンバーガーメニュー（ドロワー）
------------------------------------

- コンポーネント名案: `MobileDrawer.razor`
- 実装方式:
  - daisyUI の `drawer drawer-end` を使った右側からのスライドイン
  - もしくは `modal modal-bottom` を利用したボトムシートスタイル
- メニュー項目（例）:
  - ホーム
  - カレンダー
  - 予約一覧（将来拡張）
  - 設定（将来拡張）
- PC 版との切り替えは行わない
  - 元仕様の通り、モバイルで PC 版を表示した場合も自動切り替えはせず、切り替えには開きなおし（再ログイン）が必要という前提は維持する


10. アバターグループ
--------------------

- コンポーネント名案: `MobileAvatarGroup.razor`
- UI:
  - daisyUI の `avatar-group -space-x-4` を利用
  - 最大3人のアバターを表示し、残り人数は `+N` のカウンターとして表示する
- データ:
  - 既存の SignalR ハブ（例: `/hubs/appointmentStats` や別ハブ）からオンラインユーザー情報を取得する前提
- サイズ:
  - アバター画像サイズは `w-8 h-8` などモバイル向けにやや小さめとする


11. 自アバターメニュー
-----------------------

- コンポーネント名案: `MobileSelfAvatar.razor`
- 表示:
  - ステータスインジケーター付きアバター（online: 緑, away: 黄, busy: 赤 など）
- 動作:
  - タップでドロップダウンメニューを表示する（`dropdown dropdown-end`）
  - メニュー例:
    - プロフィール
    - 設定
    - テーマ切替
    - 施設切替
    - ログアウト
- 実装:
  - 既存 `UserAvatarFab` のロジックを参考にしつつ、モバイル向けに配置とサイズを調整する


12. 予約作成モーダル
--------------------

- コンポーネント名案: `MobileAppointmentModal.razor`
- 表示形式:
  - フルスクリーンモーダルとして表示する
  - 例: `modal modal-open` + `modal-box w-full h-full max-w-full max-h-full`
- フィールド:
  - 予約日（プリセットされる、選択した日付）
  - ステータス（予約 / 仮予約 / その他）
  - 開始時間（30分刻みなど既存ロジックに準拠）
  - 患者名
  - 団体名
  - リソース（機器等、複数選択可）
  - メモ
- モバイル向け調整:
  - 各フィールドは縦方向に1カラムで並べる
  - 入力コンポーネントは `input-sm` 相当の高さでそろえる
  - リソース選択は `collapse` で折りたためるようにし、画面の縦スペースを節約する
- 保存・キャンセル:
  - 画面下部に「保存」「キャンセル」ボタンを横並びで配置する


13. データフロー（概要）
-------------------------

- ログイン時:
  - `AuthController` が User-Agent を判定し、モバイルなら `/m/calendar` に遷移させる
- `/m/calendar` 画面:
  - `MobileCalendarLayout` がルートレイアウトとして読み込まれる
  - レイアウト内で `MobileMonthCalendar` または `MobileDayCalendar` を表示する
  - データは既存の `CalendarOrchestrator` と `CalendarState` から取得する
- フィルター:
  - `MobileFilterSheet` で指定した条件を `CalendarState` 相当のフィルター構造に反映し、
    カレンダー表示用データの取得・絞り込みに利用する
- 予約作成:
  - ロングプレスメニューから `MobileAppointmentModal` を開き、
    保存時に既存の Orchestrator 経由で予約データを更新する
- 表示記号:
  - サーバーサイドで空き率を計算し、●▼×- のいずれかを決定してクライアントに渡す
  - クライアント側では受け取った記号と `n/m` をもとに、セル内に DOM で表示する


14. 新規コンポーネント・ユーティリティ一覧（案）
-----------------------------------------------

- `MobileCalendarLayout.razor` : モバイル専用レイアウト

- `MobileMonthCalendar.razor` : 月間カレンダー（DOMベース）

- `MobileDayDetail.razor` : 選択日詳細表示
- `MobileFilterSheet.razor` : モバイルフィルター UI
- `MobileLongPressMenu.razor` : ロングプレス時のボトムシートメニュー（予約作成 / 仮予約作成）
- `MobileAppointmentModal.razor` : ロングプレスメニュー経由で開く予約作成モーダル
- `MobileHamburgerButton.razor` : モバイル用ハンバーガーボタン
- `MobileDrawer.razor` : モバイル用ドロワーメニュー
- `MobileAvatarGroup.razor` : モバイル用アバターグループ
- `MobileSelfAvatar.razor` : モバイル用自アバター＋メニュー
- （任意）`MobileSymbolHelper` : 空き率から ●▼×- を決定するユーティリティ（サーバーサイドまたは共有ライブラリ側）
