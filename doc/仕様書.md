## 1. 概要

### 1.1 目的

RazorReportDesignerは、WPFアプリケーションでWYSIWYG（What You See Is What You Get）方式のレポートデザイナーを提供します。Razorテンプレートとして保存し、パラメータを渡してHTMLに変換し、WebView2でリアルタイムプレビューを表示します。完成したレポートはPDFに変換できます。

### 1.2 主な機能

- **WYSIWYGデザイナー**: ドラッグ&ドロップで直感的にレポートをデザイン
- **Razorテンプレート**: テンプレートエンジンによる柔軟なデータバインディング
- **リアルタイムプレビュー**: WebView2によるHTMLプレビュー表示
- **PDF出力**: WebView2の印刷機能によるPDF変換
- **8pxグリッドシステム**: 整ったレイアウトのためのグリッドスナップ機能
- **リッチテキスト編集**: フォント、スタイル、色などの詳細なテキスト編集

### 1.3 対象ユーザー

- レポートデザイナー
- 開発者
- ビジネスユーザー（基本的な操作が可能なユーザー）

### 3.2 デザイナー機能

#### 3.2.1 グリッドスナップ機能

##### グリッド表示

- **表示方法**: デザインビューに背景グリッドを表示
- **表示/非表示**: ツールバーのトグルボタンで切り替え可能
- **視覚的表現**: 点線または薄い線で表示（グリッド罫線）
- **グリッド罫線のON/OFF**: 
  - グリッド罫線を表示することで、8px単位の配置を視覚的に確認可能
  - 罫線に沿ってデザインをレイアウトできる
  - 罫線表示時も非表示時も、スナップ機能は動作する

##### スナップ機能

- **動作**: 要素を配置・移動する際に、グリッドの交点に自動的にスナップ
- **スナップ有効/無効**: トグルで切り替え可能
- **スナップ範囲**: マウスカーソルがグリッド交点の±4px以内の場合にスナップ

##### グリッドサイズ

- **デフォルト**: 8px
- **8pxグリッド準拠**: すべてのコンポーネントの位置とサイズは8pxの倍数で制約
- **制約**: 要素のX座標、Y座標、幅、高さはすべて8pxの倍数

##### 実装詳細

- 要素の配置時: `Math.Round(value / 8) * 8` で8pxの倍数に丸める
- 要素の移動時: ドラッグ中も8pxグリッドにスナップ
- 要素のリサイズ時: リサイズハンドルをドラッグする際も8pxグリッドにスナップ
- グリッド罫線の描画: 8px間隔で縦横の罫線を描画（背景レイヤー）

#### 3.2.3 テーブルコンポーネント

##### 実装方式

- **HTMLテーブル**: `<table>`タグを使用（主要実装方式）
- **CSS Grid**: オプションとして将来的にサポート可能な設計

##### テーブル作成方法

**手動作成**:
- 行・列数を指定してテーブルを作成
- 初期状態は空のセル

**テンプレートから**:
- 事前定義されたテーブルテンプレートを使用
- テンプレート例:
  - 請求書テーブル
  - 見積書テーブル
  - 一覧表
  - カレンダー形式

##### データバインディング方式

**方式1: 配列データの繰り返し表示**

- 配列データを渡すと、各行が配列の各要素に対応
- Razor構文: `@foreach(var item in Model.Items) { ... }`
- セル内で `@item.PropertyName` でプロパティにアクセス
- 例: 顧客リスト、商品一覧など

**実装例**:
```razor
<table>
    <thead>
        <tr>
            <th>商品名</th>
            <th>数量</th>
            <th>単価</th>
            <th>金額</th>
        </tr>
    </thead>
    <tbody>
        @foreach(var item in Model.Items)
        {
            <tr>
                <td>@item.ProductName</td>
                <td>@item.Quantity</td>
                <td>@item.UnitPrice</td>
                <td>@(item.Quantity * item.UnitPrice)</td>
            </tr>
        }
    </tbody>
</table>
```

**方式2: 個別値の配置**

- 各セルに個別の値を配置
- パラメータ参照: `@dic["key"]` 形式
- ドラッグ&ドロップでパラメータパネルから値を配置可能

##### テーブル編集機能

**セルの操作**:

#### 3.2.4 選択機能

##### 単一選択

- **操作**: コントロールをクリック
- **表示**: 選択されたコントロールに選択ハンドルを表示
- **プロパティパネル**: 選択されたコントロールのプロパティを表示

##### 複数選択

- **SHIFT+クリック**: 
  - 既に選択されているコントロールにSHIFTキーを押しながらクリックで追加選択
  - SHIFTキーを押しながらクリックで選択解除も可能
- **範囲選択**:
  - デザインエリア上でマウスをドラッグして範囲を指定
  - 範囲内のコントロールをすべて選択
  - 範囲選択中は半透明の矩形を表示
- **全選択**: Ctrl+Aで全コントロールを選択

##### 選択状態の表示

- **選択ハンドル**: 選択されたコントロールの周囲にハンドルを表示
- **複数選択時**: すべての選択されたコントロールにハンドルを表示
- **選択解除**: デザインエリアの空白部分をクリック

#### 3.2.5 配置揃え機能

##### 配置コマンドボタン

ツールバーに配置揃え用のコマンドボタンを配置：

**垂直方向の配置**:
- **上揃え**: 選択された複数コントロールの上端を揃える
- **中央揃え（垂直）**: 選択された複数コントロールの垂直方向の中央を揃える
- **下揃え**: 選択された複数コントロールの下端を揃える

**水平方向の配置**:
- **左揃え**: 選択された複数コントロールの左端を揃える
- **中央揃え（水平）**: 選択された複数コントロールの水平方向の中央を揃える
- **右揃え**: 選択された複数コントロールの右端を揃える

##### 配置基準

- **基準コントロール**: 最初に選択されたコントロール、または最後に選択されたコントロールを基準とする
- **配置後の位置**: 8pxグリッドにスナップして配置
- **複数選択時のみ有効**: 2つ以上のコントロールが選択されている場合のみボタンが有効化

##### 実装詳細

- 配置コマンド実行時: すべての選択コントロールの位置を計算し、基準コントロールに合わせて配置
- 配置後: `Math.Round(value / 8) * 8` で8pxの倍数に丸める

#### 3.2.6 オブジェクトスナップ機能

##### オブジェクト間スナップ

- **動作**: Altキーを押しながらコントロールをドラッグすると、グリッドスナップを無効化し、代わりに他のコントロールにスナップ
- **スナップ対象**: 
  - 他のコントロールの端（上、下、左、右）
  - 他のコントロールの中心点
  - 他のコントロールの角
- **視覚的フィードバック**: スナップ時にガイドライン（青い線）を表示
- **スナップ範囲**: マウスカーソルがスナップ対象の±4px以内の場合にスナップ

##### グリッドスナップとの切り替え

- **通常時**: 8pxグリッドにスナップ（Altキーを押していない場合）
- **Altキー押下時**: オブジェクト間スナップに切り替え
- **両方無効化**: 設定でスナップ機能を無効化可能

##### 実装詳細

- Altキーの検出: `Keyboard.IsKeyDown(Key.LeftAlt)` または `Keyboard.IsKeyDown(Key.RightAlt)`
- スナップ判定: ドラッグ中のコントロールの位置と他のコントロールの位置を比較
- ガイドライン表示: スナップ時に一時的にガイドラインを描画

#### 3.2.7 ダブルクリック編集機能

##### 全コンポーネント対応

すべてのコンポーネントでダブルクリックによる編集をサポート：

- **テキストコンポーネント**: ダブルクリックでインライン編集モード（テキスト内容の直接編集）
- **画像コンポーネント**: ダブルクリックで画像ファイル選択ダイアログを開く
- **テーブルコンポーネント**: ダブルクリックでセル編集モード（セル内のテキスト編集）
- **Razorコードブロック**: ダブルクリックでコード編集ダイアログを開く
- **コンテナ/セクション**: ダブルクリックでプロパティパネルを表示（または編集ダイアログ）

##### 編集モード

- **インライン編集**: テキストコンポーネントやテーブルセルで、その場で編集可能な状態にする
- **ダイアログ編集**: 画像やコードブロックなど、複雑な編集が必要な場合は専用ダイアログを表示
- **編集終了**: Enterキー、Escキー、またはフォーカスアウトで編集終了

#### 3.2.8 ドラッグ&ドロップ機能

##### コンポーネントの配置

**ツールパレットからデザインエリアへ**:
1. ツールパレットでコンポーネントを選択
2. マウスでドラッグ
3. デザインエリアにドロップ
4. 8pxグリッドに自動スナップして配置

**視覚的フィードバック**:
- ドラッグ中は半透明のプレビューを表示
- ドロップ可能な領域をハイライト
- スナップ位置を表示

##### データの配置

**パラメータパネルからコンポーネントへ**:
1. パラメータパネルでキーを選択
2. マウスでドラッグ
3. テキストコンポーネントやテーブルセルにドロップ
4. 自動的に `@dic["key"]` 形式のRazorコードに変換

**変換ルール**:
- テキストコンポーネント: 既存テキストに `@dic["key"]` を追加、または置換
- テーブルセル: セル内容を `@dic["key"]` に置換

### 3.3 Razorテンプレート

#### 3.3.1 保存形式

- **ファイル形式**: `.razor`ファイルのみ
- **メタデータ**: 含まない（純粋なRazorテンプレート）
- **エンコーディング**: UTF-8

#### 3.3.2 パラメータ

**形式**: `Dictionary<string, string>`形式で渡す

**アクセス方法**:
- テンプレート内で`@Model`としてアクセス可能
- `@dic`というエイリアスも使用可能（設定による）

#### 3.3.3 パラメータ参照構文

**Dictionary形式**:
- `@dic["key"]` または `@Model["key"]`
- キーが存在しない場合は空文字列を返す（エラーは発生しない）

**モデルプロパティ**（将来拡張用）:
- `@Model.PropertyName`
- 強く型付けされたモデルを使用する場合

**配列アクセス**:
- `@Model.Items[i].PropertyName`
- JSON文字列をパースして使用

#### 3.3.4 パラメータの型

**基本型**:
- すべて文字列（`Dictionary<string, string>`）
- 数値や日付も文字列として扱う

**配列データ**:
- JSON文字列として渡し、Razor内でパース
- 例: `@JsonSerializer.Deserialize<List<Customer>>(Model["customers"])`

**実装例**:
```csharp
// C#側
var parameters = new Dictionary<string, string>
{
    ["customerName"] = "山田太郎",
    ["amount"] = "10000",
    ["items"] = "[{\"name\":\"商品A\",\"price\":1000}]"
};
```

```razor
<!-- Razorテンプレート側 -->
<div>顧客名: @dic["customerName"]</div>
<div>金額: @dic["amount"]円</div>
@{
    var items = JsonSerializer.Deserialize<List<Item>>(dic["items"]);
}
@foreach(var item in items)
{
    <div>@item.Name: @item.Price円</div>
}
```

## 6. アーキテクチャパターン

### 6.1 MVVMパターン

#### 6.1.1 パターンの採用

- **パターン**: Model-View-ViewModel (MVVM) パターンを採用
- **目的**: UIとビジネスロジックの分離、テスタビリティの向上

#### 6.1.2 実装

- **実装**: ReactiveProperty (R3) を使用してViewModelを実装
- **データバインディング**: ReactivePropertyによる双方向バインディング
- **コマンド**: ReactiveCommandを使用したコマンド実装

#### 6.1.3 責務分離

**Model**:
- データ構造の定義
- ビジネスロジック（可能な限り）

**View**:
- UIの表示
- ユーザー入力の受け取り
- ViewModelへのデータバインディング

**ViewModel**:
- ViewとModelの仲介
- コマンドの実装
- 状態管理

### 6.2 ViewModelの責務

#### 6.2.1 MainViewModel

- アプリケーション全体の状態管理
- ビューモード切り替え（デザインビュー/プレビュービュー）
- ファイル操作（新規作成、開く、保存）

#### 6.2.2 DesignerViewModel

- デザイン要素の管理
- グリッド設定（表示/非表示、スナップ有効/無効）
- 選択要素の管理
- 要素の追加・削除・移動

#### 6.2.3 PreviewViewModel

- プレビュー表示の管理
- HTML生成のトリガー
- WebView2の制御

#### 6.2.4 ParameterViewModel

- パラメータの管理（`Dictionary<string, string>`）
- パラメータの追加・編集・削除
- サンプルデータの読み込み

## 7. 制約事項

### 7.1 ファイル形式

- Razorテンプレートは`.razor`ファイルのみで保存（メタデータなし）
- メタデータが必要な場合は別ファイル（`.razor.meta`等）に保存（将来拡張）

### 7.2 パラメータの型

- パラメータはすべて文字列型（`Dictionary<string, string>`）
- 数値や日付も文字列として扱う
- 型変換はRazorテンプレート内で行う

### 7.3 PDF変換

- PDF変換はWebView2の印刷機能に依存
- WebView2ランタイムがインストールされている必要がある

### 7.4 MVVMパターン

- MVVMパターンはReactiveProperty (R3) を使用して実装
- 他のMVVMフレームワーク（Prism、MVVMLight等）は使用しない

### 7.5 グリッドシステム

- すべてのコンポーネントの配置・サイズは8pxグリッドに準拠
- 8pxの倍数以外の値は使用できない

### 7.6 プラットフォーム

- Windows専用（WPFの制約）
- .NET 10.0以上が必要

## 8. エラーハンドリング

### 8.1 ファイル操作エラー

**読み込みエラー**:
- ファイルが存在しない場合: エラーメッセージを表示
- ファイル形式が不正な場合: エラーメッセージを表示
- アクセス権限がない場合: エラーメッセージを表示

**保存エラー**:
- ディスク容量不足: エラーメッセージを表示
- アクセス権限がない場合: エラーメッセージを表示
- ファイルがロックされている場合: エラーメッセージを表示

### 8.2 Razorテンプレートエラー

**コンパイルエラー**:
- シンタックスエラー: エラーメッセージと行番号を表示
- 型エラー: エラーメッセージを表示
- プレビュー更新時にエラーを検出

**実行時エラー**:
- パラメータが存在しない場合: 空文字列を返す（エラーは発生しない）
- 配列のインデックス範囲外: エラーメッセージを表示
- JSONパースエラー: エラーメッセージを表示

### 8.3 WebView2エラー

**初期化エラー**:
- WebView2ランタイムがインストールされていない場合: インストールを促すメッセージを表示
- 初期化に失敗した場合: エラーメッセージを表示

**プレビュー表示エラー**:
- HTMLのレンダリングエラー: エラーメッセージを表示
- ネットワークエラー（Googleフォント読み込み等）: 警告メッセージを表示（フォールバック）

### 8.4 ユーザー入力エラー

**バリデーション**:
- 無効な値の入力: エラーメッセージを表示
- 必須項目の未入力: エラーメッセージを表示

**エラーメッセージの表示**:
- ツールバーにエラーアイコンを表示
- エラーパネルに詳細を表示（オプション）

## 11. 用語集

| 用語 | 説明 |
|------|------|
| WYSIWYG | What You See Is What You Get（見たままが得られる）の略。編集画面と出力結果が一致する編集方式 |
| Razor | Microsoftが開発したテンプレートエンジン。C#コードをHTMLに埋め込むことができる |
| WebView2 | Microsoftが提供するWebブラウザコントロール。Chromiumベース |
| MVVM | Model-View-ViewModelの略。UIとビジネスロジックを分離するアーキテクチャパターン |
| ReactiveProperty | リアクティブプログラミングをサポートするプロパティライブラリ |
| 8pxグリッド | 8ピクセル単位のグリッドシステム。整ったレイアウトを実現するための設計手法 |
| スナップ | 要素を配置・移動する際に、グリッドの交点に自動的に配置する機能 |
| コンポーネント | レポートを構成する要素（テキスト、画像、テーブル等） |
| パラメータ | Razorテンプレートに渡すデータ。キー・値のペアで管理 |
| プレビュー | レンダリング結果を事前に確認する機能 |
