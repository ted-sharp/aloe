# RazorReportDesigner 仕様書

作成日: 2026-01-21

## 1. 概要

RazorReportDesignerは、WPFアプリケーションでWYSIWYG（What You See Is What You Get）方式のレポートデザイナーを提供します。Razorテンプレートとして保存し、パラメータを渡してHTMLに変換し、WebView2でリアルタイムプレビューを表示します。完成したレポートはPDFに変換できます。

## 2. アーキテクチャ

### 2.1 プロジェクト構成

- **Aloe.Apps.RazorReportDesigner** (WPFアプリ本体)
  - WebView2によるプレビュー表示
  - UI操作（デザイン編集、プレビュー切り替え）
  - パラメータ管理UI
  - PDF出力機能

- **Aloe.Apps.RazorReportDesignerLib** (コアライブラリ)
  - Razorテンプレートの読み込み・保存
  - RazorテンプレートからHTMLへの変換
  - デザイン要素のモデル定義
  - テンプレートエンジンとの連携

### 2.2 データフロー

```
デザイナーUI → デザインモデル → Razorテンプレート(.razor)
                                    ↓
パラメータ(Dictionary<string, string>) → HtmlRenderer → HTML
                                    ↓
                                WebView2 → プレビュー表示
                                    ↓
                                WebView2印刷機能 → PDF
```

## 3. 機能仕様

### 3.1 UI構成

- **単一ビューモード**: デザインビューとプレビュービューを切り替え表示
- **ツールバー**: 要素追加、保存、プレビュー切り替え、PDF出力などのボタン
- **プロパティパネル**: 選択要素のプロパティ編集
- **パラメータパネル**: テンプレートパラメータの編集UI
- **デザイングリッド**: デザインビューにグリッドを表示し、要素配置時にスナップ機能を提供

### 3.2 デザイナー機能

#### 3.2.1 グリッドスナップ機能

- **グリッド表示**: デザインビューに背景グリッドを表示
- **スナップ機能**: 要素を配置・移動する際に、グリッドの交点に自動的にスナップ
- **グリッドサイズ**: 設定可能（デフォルト: 10pxなど）
- **スナップ有効/無効**: トグルで切り替え可能

#### 3.2.2 サポート要素

以下の要素をデザイナーでサポートします：

1. **テキスト**
   - プレーンテキスト
   - フォント、サイズ、色、スタイルの設定

2. **画像**
   - 画像ファイルの読み込み
   - サイズ調整

3. **テーブル**
   - 行・列の追加・削除
   - セルの結合
   - スタイル設定

4. **Razorコードブロック**
   - C#コードの直接記述
   - パラメータの参照（@Model.パラメータ名）

### 3.3 Razorテンプレート

- **保存形式**: `.razor`ファイルのみ（メタデータは含まない）
- **パラメータ**: `Dictionary<string, string>`形式で渡す
- **モデル**: テンプレート内で`@Model`としてアクセス可能

### 3.4 プレビュー機能

- **更新方式**: 手動更新（ボタンクリックで更新）
- **表示**: WebView2コントロールでHTMLを表示
- **リアルタイム性**: デザイン変更後、手動でプレビューを更新

### 3.5 PDF変換

- **方法**: WebView2の印刷機能を使用
- **出力**: PDFファイルとして保存

### 3.6 パラメータ管理

- **UI**: パラメータ編集用の専用パネルを提供
- **形式**: キー・値のペアで編集可能
- **型**: すべて文字列（`Dictionary<string, string>`）

## 4. 技術スタック

### 4.1 フレームワーク・ライブラリ

- **.NET 10.0**: ターゲットフレームワーク
- **WPF**: UIフレームワーク
- **WebView2**: HTMLプレビュー表示
- **Razor Engine**: Razorテンプレートのコンパイル・実行
  - 候補: RazorEngine.NetCore, RazorLight, またはMicrosoft.AspNetCore.Razor.Runtime
- **ReactiveProperty (R3)**: MVVMパターン実装のためのリアクティブプロパティライブラリ
  - ViewModelでのデータバインディングとコマンド処理に使用

### 4.2 必要なNuGetパッケージ（予定）

- Microsoft.Web.WebView2
- RazorEngine.NetCore または RazorLight（Razorテンプレート処理）
- ReactiveProperty (R3) - MVVMパターン実装用
- System.Text.Json（設定ファイル処理、必要に応じて）

## 6. アーキテクチャパターン

### 6.1 MVVMパターン

- **パターン**: Model-View-ViewModel (MVVM) パターンを採用
- **実装**: ReactiveProperty (R3) を使用してViewModelを実装
- **データバインディング**: ReactivePropertyによる双方向バインディング
- **コマンド**: ReactiveCommandを使用したコマンド実装

### 6.2 ViewModelの責務

- **MainViewModel**: アプリケーション全体の状態管理、ビューモード切り替え
- **DesignerViewModel**: デザイン要素の管理、グリッド設定、スナップ機能
- **PreviewViewModel**: プレビュー表示の管理、HTML生成のトリガー
- **ParameterViewModel**: パラメータの管理（Dictionary<string, string>）

## 7. 制約事項

- Razorテンプレートは`.razor`ファイルのみで保存（メタデータなし）
- パラメータはすべて文字列型（`Dictionary<string, string>`）
- PDF変換はWebView2の印刷機能に依存
- MVVMパターンはReactiveProperty (R3) を使用して実装
