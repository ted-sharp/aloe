# コンポーネントとパラメータ定義

## コンポーネントライブラリ

### コンポーネントの配置方法

すべてのコンポーネントは以下の2つの方法で配置できます：

#### 方法1: クリック選択→範囲ドラッグ（既存方式）

1. **コンポーネント選択**: ツールおよびパラメータパレットでコンポーネントをクリックして選択（配置モード有効化）
2. **範囲指定**: デザインエリア内で配置したい範囲をドラッグして指定
3. **自動配置**: ドロップ時に選択されたコンポーネントが、指定した範囲のサイズで自動配置される

配置後は配置モードが自動解除され、通常の編集モードに戻ります。

#### 方法2: ドラッグ&ドロップ（新規方式）

1. **ドラッグ開始**: ツールおよびパラメータパレットのコンポーネントアイテムをドラッグ開始
2. **ドラッグ中**: カーソルが配置可能アイコンに変更、デザインエリア上でドロップ可能位置をハイライト表示
3. **ドロップ**: ドロップ位置のグリッドセルに、設定ファイル（`appsettings.components.json`）で定義されたデフォルトサイズで自動配置
4. **配置後**: 配置されたコンポーネントを自動選択し、通常の編集モードに移行

**デフォルトサイズ**: 各コンポーネントタイプのデフォルトサイズは`appsettings.components.json`で定義されます。詳細は[appsettings.components.jsonの構造](#appsettingscomponentsjsonの構造)を参照してください。

### テキストコンポーネント

**機能**:
- プレーンテキストの表示・編集
- リッチテキストエディタ対応
- インラインスタイル（Bold、Italic、Underline、Strikethrough）
- フォント、サイズ、色、スタイルの設定
- Googleフォント対応

**プロパティ**:
- テキスト内容
- 参照プロパティ（パラメータキーを指定。HTML/PDF作成時にキーワードが値になる）
- フォントファミリー
- フォントサイズ
- フォントカラー
- 背景色
- 配置（左、中央、右、両端）
- 位置（グリッドセル: column, row）
- サイズ（グリッドセル: columnSpan, rowSpan）

**参照プロパティ**:
- パラメータキーを指定することで、HTML/PDF作成時に実際のパラメータ値に置き換えられる
- プロパティパネルから直接設定可能、またはパラメータパレットからドラッグ&ドロップで設定可能
- JSONでは参照プロパティとして保持され、Razorファイル組み立て時に`@dic["key"]`形式に変換される

**編集方法**:
- ダブルクリックでインライン編集モード（テキスト内容の直接編集）
- プロパティパネルで詳細設定
- ツールバーでスタイル適用

### 画像コンポーネント

**機能**:
- 画像ファイルの読み込み（PNG、JPEG、GIF、SVG等）
- サイズ調整（グリッドセルにスナップ、常時有効）
- アスペクト比の維持（オプション）

**プロパティ**:
- 画像ファイルパス
- サンプル画像パス（データ表示モード用）
- 位置（グリッドセル: column, row）
- サイズ（グリッドセル: columnSpan, rowSpan）
- アスペクト比維持フラグ
- カスタムプロパティ（任意）

**操作**:
- 画像ファイルをドラッグ&ドロップで配置
- 選択後にドラッグで移動、リサイズハンドルでサイズ調整
- ダブルクリックで画像ファイルを選択・変更

### テーブルコンポーネント

**実装方式**: HTMLテーブル（`<table>`タグ）を使用。

**テーブル作成**: 手動作成（行・列数を指定）またはグリッド範囲選択から作成（選択範囲の列数×行数のセルを持つテーブルが作成される）。

**テーブル編集**: 行・列の追加/削除、セルの結合/分割、セルの内容編集。スタイル設定（セル背景色、ボーダー、パディング、テキスト配置）。ヘッダー行の指定とスタイル設定。

**グリッドセル準拠**: テーブル全体の位置とサイズはグリッドセル単位で管理（column, row, columnSpan, rowSpan）。テーブル内で行・列を追加/削除しても、テーブル全体のサイズは自動的には変更されない（リサイズハンドルで手動調整が必要）。

**デフォルトサイズ**: テーブルコンポーネントのデフォルトサイズには、グリッドセル単位のサイズ（columnSpan, rowSpan）に加えて、テーブル内部の列数（defaultColumns）と行数（defaultRows）も含まれます。これらは`appsettings.components.json`で定義されます。

### レイアウトコンポーネント

**コンテナ（div相当）**: 
- 複数の要素をグループ化、背景色・ボーダー・パディングの設定
- **グリッド配置**: CSS subgridを使用して親グリッド（36列×51行）を継承
  - コンテナ自体はルートグリッドに対して配置される（column, row, columnSpan, rowSpan）
  - コンテナ内の子要素は、コンテナがスパンする範囲内で親グリッドを継承して配置される
  - 子要素の座標は、コンテナ内での相対座標（1から始まる）で管理される
- フレックスボックスやグリッドレイアウトの設定（将来拡張）

## パラメータ管理

### UI

- **統合パネル**: ツールおよびパラメータパレット内でパラメータ管理を提供
- **表示形式**: キー・値のペアで編集可能
- **操作**: 追加、編集、削除が可能
- **ドラッグ&ドロップ対応**: ツールおよびパラメータパレットからコンポーネントへドラッグ&ドロップ可能

### 形式

- **データ形式**: キー・値のペア
- **型**: すべて文字列（`Dictionary<string, string>`）
- **管理方式**: JSON形式で管理
  - パラメータキー一覧とサンプル値は`appsettings.parameters.json`で定義（[appsettings.parameters.jsonの構造](#appsettingsparametersjsonの構造)を参照）
  - パラメータをJSONファイルに保存・読み込み可能
- **実行時**: JSONから読み込んだパラメータは`Dictionary<string, string>`に変換されてメモリで管理

### ドラッグ&ドロップ

- **操作**: ツールおよびパラメータパレットからコンポーネントへ値をドラッグ&ドロップ
- **参照プロパティ設定**: ドロップ時に、コンポーネントの参照プロパティにパラメータキーが設定される
- **対応コンポーネント**:
  - **テキストコンポーネント**: 参照プロパティにパラメータキーを設定（既存テキストに追加、または置換）
  - **テーブルセル**: セルの参照プロパティにパラメータキーを設定
- **視覚的フィードバック**: ドラッグ中はドロップ可能なコンポーネントをハイライト表示
- **Razorコード変換**: 参照プロパティはJSON形式で保持され、Razorファイル組み立て時に`@dic["key"]`形式に自動変換される（詳細は[参照プロパティとRazorコード変換](#参照プロパティとrazorコード変換)を参照）

### パラメータの配置ルール

パラメータをデザインエリアにドラッグ&ドロップで配置する際のルール：

- **通常のパラメータ**: テキストコンポーネントとして、参照プロパティが設定された状態で配置される
- **画像キー**: 画像コンポーネントとして配置される
- **配列キー**: テーブルコンポーネントとして配置される
- **パラメータのリスト**: `appsettings.parameters.json`で定義されているものとする

### 参照プロパティとRazorコード変換

**JSONでの保持形式**:
- コンポーネントの参照プロパティは、JSONファイル内でパラメータキー（文字列）として保持される
- 例: `"referenceProperty": "companyName"` のように、`@dic["key"]`形式ではなく、キー名のみを保持

**Razorファイル組み立て時の変換**:
- JSONからRazorファイルを組み立てる際に、参照プロパティが設定されている場合は、該当箇所を`@dic["key"]`形式のRazorコードに自動変換される
- テキストコンポーネントの場合: テキスト内容に参照プロパティが設定されている場合、`@dic["key"]`が挿入される
- テーブルセルの場合: セルの参照プロパティが設定されている場合、セル内容が`@dic["key"]`に置き換えられる

**プレビュー時の動作**:
- デザイン時: 参照プロパティが設定されている場合、サンプル値（`appsettings.parameters.json`の`sampleValue`）を表示
- プレビュー時: 実際のパラメータ値を使用してレンダリング（Razorコードが実行され、`@dic["key"]`が実際の値に置き換えられる）

## パラメータのプレビュー

### プレビュー時のサンプル値使用

- **サンプル値の定義**: `appsettings.parameters.json`に各パラメータの`sampleValue`を定義（[appsettings.parameters.jsonの構造](#appsettingsparametersjsonの構造)を参照）
- **プレビュー動作**: プレビュー表示時は、`appsettings.parameters.json`に定義された`sampleValue`を自動的に使用してレンダリング
- **値の上書き**: ユーザーがツールおよびパラメータパレットで値を変更した場合は、変更後の値を使用

### パラメータ管理の動作

- **初期表示**: `appsettings.parameters.json`からキー一覧を読み込み、各キーの`sampleValue`を初期値として表示（ツールおよびパラメータパレット内）
- **値の編集**: ユーザーがツールおよびパラメータパレット内で値を編集可能
- **プレビュー反映**: 値の変更は即座にプレビューに反映される

## appsettings.parameters.jsonの構造

パラメータキー一覧とサンプル値を定義：

```json
{
  "parameters": [
    {
      "key": "companyName",
      "displayName": "会社名",
      "sampleValue": "株式会社サンプル",
      "type": "string",
      "description": "会社名を指定します"
    },
    {
      "key": "date",
      "displayName": "日付",
      "sampleValue": "2026-01-24",
      "type": "date",
      "description": "日付を指定します"
    }
  ]
}
```

**項目**: 
- `key`: コンポーネントの参照プロパティとして設定されるパラメータキー。JSONでは参照プロパティとして保持され、Razorファイル組み立て時に`@dic["key"]`形式に自動変換される
- `displayName`: UI表示名
- `sampleValue`: プレビュー時に使用
- `type`: string, number, date, array等
- `description`: 説明

プレビュー時は`sampleValue`を自動使用（ツールおよびパラメータパレットで変更可能）。

## appsettings.components.jsonの構造

コンポーネントのデフォルトサイズ設定を定義します：

```json
{
  "components": {
    "Text": {
      "columnSpan": 12,
      "rowSpan": 2
    },
    "Image": {
      "columnSpan": 6,
      "rowSpan": 4
    },
    "Table": {
      "columnSpan": 12,
      "rowSpan": 8,
      "defaultColumns": 3,
      "defaultRows": 4
    },
    "Container": {
      "columnSpan": 12,
      "rowSpan": 8
    }
  }
}
```

**項目**:
- `components`: 各コンポーネントタイプのデフォルトサイズ設定
  - `Text`: テキストコンポーネントのデフォルトサイズ
  - `Image`: 画像コンポーネントのデフォルトサイズ
  - `Table`: テーブルコンポーネントのデフォルトサイズ
  - `Container`: レイアウトコンテナのデフォルトサイズ

**各コンポーネントの設定項目**:
- `columnSpan`: デフォルトの列幅（グリッドセル単位、1以上）
- `rowSpan`: デフォルトの行高（グリッドセル単位、1以上）
- `defaultColumns`（テーブルのみ）: テーブルのデフォルト列数（1以上）
- `defaultRows`（テーブルのみ）: テーブルのデフォルト行数（1以上）

**使用タイミング**: ツールパレットからコンポーネントをドラッグ&ドロップで配置する際に、この設定ファイルで定義されたデフォルトサイズが使用されます。クリック選択→範囲ドラッグ方式の場合は、ユーザーが指定した範囲のサイズが使用されます。

## コンポーネントの配置後の操作

### 移動操作

配置済みのコンポーネントは、以下の手順で移動できます：

1. **選択**: コンポーネントをクリックで選択
2. **ドラッグ開始**: 選択されたコンポーネント上でドラッグ開始（リサイズハンドル以外の領域）
3. **ドラッグ中**: 半透明プレビューを表示、グリッドスナップ位置を表示
4. **ドロップ**: 新しい位置に移動、JSONを更新

**注意**: 移動時もグリッドセルにスナップ（常時有効）。他のコンポーネントとの重なりは許可されます（z-indexで制御）。

### リサイズ操作

配置済みのコンポーネントは、以下の手順でリサイズできます：

1. **選択**: コンポーネントをクリックで選択（リサイズハンドルを表示）
2. **リサイズ開始**: 8方向のリサイズハンドルのいずれかをドラッグ開始
3. **リサイズ中**: サイズ変更のプレビューを表示、グリッドセル単位でスナップ
4. **ドロップ**: 新しいサイズを確定、JSONを更新

**リサイズハンドル**:
- **表示条件**: コンポーネントが選択されている時のみ表示
- **位置**: コンポーネントの四隅と各辺の中点（計8箇所）
- **カーソル**: 各ハンドルで適切なリサイズカーソルを表示（↔、↕、↖、↗、↙、↘）
- **スナップ**: リサイズ時もグリッドセルにスナップ（常時有効）

**最小サイズ**: すべてのコンポーネントは最小1×1グリッドセルサイズを維持します。
